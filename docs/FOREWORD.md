# 序：把《周易》的方法论内核接上现代认识工具

## 一、缘起：从一次随机数起卦说起

这个工程的起点小得有点寒碜：一次聊天，聊到《周易》的常识，随手用随机数起了一卦——前六个数按奇偶定爻，第七个数对六取余定动爻，得**地泽临 ䷒ 之 水地师 ䷆**，动在初九。按传统路数，接下来该是断一断吉凶。但我们做的第一件事是掉头：把卦辞爻辞当文本读，问它到底在说什么。

"临，刚浸而长。"——原来这句话讲的不是天机，是**量变积累期**的形势判断。"至于八月有凶。"——《彖传》自己解释为"消不久也"：盛势里含着反转，优势有保质期。这哪是玄学，这是一份写在三千年前的形势分析。起卦记录至今留在 19-临 的附录里，但它只是引子与史料；按本工程的认识论，"动爻"应由调研找出关键变量，而不是由随机数决定。

从那次聊天往后，事情长成了现在这个样子：六十四卦逐一过手，每卦走完五道工序，配现代实例，做血统标注，前后十二期、一百余条可溯源案例。它不再是一次谈资，而是一门可以持续推进、可以被别人接手的转译工作。

## 二、主张：分水岭不在智慧，在方法

对待《周易》，常见的两端都不对：一端把它神化为玄学，仿佛卦里藏着对未来的密报；一端把它贬为江湖术数，不值一哂。我们取中间立场：古人看到的不只是象，也是规律的雏形——只是规律的表述方式、检验方式、传输方式与现代不同。

真正的分水岭不在智慧的有无，而在**方法能否自我纠错、能否稳定地传给下一个不那么"神而明之"的人**。凡是依赖"悟性""机缘""心诚则灵"才能运转的，都传不远；凡是写得下步骤、标得出边界、容得下反例的，才接得上现代认识工具。本工程押注的就是后一条路。

这个标准并不苛刻，它其实就是现代学术与工程的日常：把结论写到别人可以复核的程度。《系辞》说"不可为典要，唯变所适"，本来就反对把文本当教条；汉象数、魏玄学、宋理学、近世哲学都曾往里注入新血，注而不垮，说明这个文本的承重力本来就允许被重新解释——问题只在解释得老不老实。

## 三、五道工序与三条纪律的来历

五道工序不是先设计好再填空的，是被文本和教训逼出来的：

1. **训诂先行**——"咸临"的"咸"是感通还是普遍？"至于八月"怎么数？字义没站稳就谈引申，全是空中楼阁。拿不准就标"存疑"，两解并列，绝不编造。
2. **还原语境**——这一卦在处理什么具体问题？创业起手？带队伍？搞改革？卦不是格言集，是场景应对记录。
3. **抽出结构**——剥掉龙、马、水、火的象，留下阶段、呼应、消长、位次这些关系结构。
4. **现代重述**——写成今天能用的判断，逐句标注血统。
5. **实践检验**——找反例、加条件句、划适用边界，落到可执行清单与真实案例。

三条纪律同样是从实践中收出来的：**结构可对接、内容不等同**——"刚浸而长"对接"矛盾消长"是结构映射，不是说古人懂得唯物辩证法；**保持双向张力**——以今释古，也以古益今，卦辞照得出现代管理学的盲区（过度自信、忽视趋势反转、忽视人心感通）；**最终落回实践**——不可检验的结论，只是换了套词汇的玄谈。

## 四、为什么坚持留白

这套方法最费力的地方，是承认有些地方转不动。三处我们选择留白：一是**循环史观**——"盛衰有定数、天道好还"式的循环宇宙观与历史唯物主义相抵，标注 [不可通约]，不硬接；二是**君子—小民框架**——古代政治想象里没有个体权利、程序正义的位置，"容保民无疆"可以引申为普惠逻辑，但主体必须换，换了就老实说是引申；三是**占断功能本身**——原文的"吉""凶"只作训诂对象，转译时一律还原为条件后果（做对了会怎样、做错了会怎样），不做未来判断。

宁可空着，不可含混。留白不是谦虚，是精度：一段含混的"贯通"，会把整套方法的信用赔进去。反过来，能在留白处守住分寸，那些标了 [转译] 的判断才有分量。

## 五、这本书怎么用

先说清楚它**不是**什么：不是占卜书，不是成功学，不是《周易》全译本。它是一部**方法论实验记录**——六十四篇统一模板，每篇都摊开同一条流水线：训诂、语境、结构、现代转译、实践清单、卦际关联。你可以顺着读，也可以按主题簇跳读（怎么读见 [GUIDE.md](GUIDE.md)）。

它给出的一切判断，都只是**可检验的假说**。现代实例是检验材料，不是预测论据；案例做得再漂亮，也不能替代你自己手上的调研数据。结论成不成立，要靠实证说了算。至于注疏分歧、训诂存疑、数字待核之处，我们一律照实标注——这些"没搞定"的记号，和"搞定"的部分同样重要。

## 六、免责

本工程全部产出**不构成任何占卜、预测、决策或投资建议**。原文中的"吉""凶"等字样仅为训诂引用，转译中一律还原为条件—后果描述，不含任何面向未来的判断。凡据本书内容做出的任何决定，责任由决定者自负；唯一负责任的用法，是把这里的判断当假说，拿去调研、检验、修正。

是为序。
