# 导读：怎么读这本书

这份导读解决三个问题：这本书长什么样、按什么顺序读、读的时候拿什么自检。

## 一、全书结构：六十四篇，一个模板

全书主体是 `hexagrams/` 下的六十四篇，每篇严格六节，节名与顺序完全一致——**统一模板本身就是方法的一部分**，它让任何两卦都可以横向对照，也让后来者可以接手、复核、挑错。

以 19 临 为例，六节各在干什么：

1. **一、训诂**——把卦辞、彖、象、爻辞摆出来，逐一过关键字词的本义、通假与主流注疏分歧；拿不准的标"存疑"，两解并列。这一节在说：**原文到底说了什么，以及我们在哪里没把握**。
2. **二、语境**——这一卦在处理什么具体问题？创业起手、带队伍、搞改革，还是守成善后？落到现代实际场景。这一节在说：**这是给谁在什么处境下用的**。
3. **三、结构**——剥掉龙马水火的象，留下关系结构（阶段、呼应、消长、位次），以"易学结构 ↔ 抽出的关系结构"对照表呈现。这一节在说：**哪些是可对接的骨架**。
4. **四、现代转译**——新断词：写成今天能用的判断，逐句标注 [转译]/[引申]/[不可通约]，并附"双向张力"小段（现代概念给卦辞什么分辨率、卦辞照出现代方法什么盲区）。这一节在说：**换成今天的语言，结论是什么**。
5. **五、实践清单**——可执行判断、适用条件、反例与边界、验证方式，其后附 **现代实例**小节（真实可溯源案例，四行格式）。这一节在说：**怎么用、用在哪、哪里会失效**。
6. **六、与其他卦的关联**——接上卦际结构线（互综、相错、消长主线、主题簇）。这一节在说：**这卦在整张网里的坐标**。读到这里停一下：把关联卦名抄在纸上，你会发现六十四篇其实织成了几张互相嵌套的结构线。

## 二、三遍阅读法

- **第一遍：只读"现代转译"节**。取判断，看结论顺不顺、硬不硬。觉得哪句可疑，记下来。
- **第二遍：回头读"结构"节与血统标注**。查每个判断的出身：是 [转译]（原文有对应结构）还是 [引申]（借结构延伸，须换主体的也在此列）？标注不支持的句子，第一遍的感动就该打折。
- **第三遍：拿"实践清单"自检**。对照自己手上的事：适用条件满足吗？反例边界踩到了吗？验证方式能落地吗？再看现代实例的"可核验边界"行，学着给自己的判断划边界。

三遍下来，你得到的不是六十四条金句，而是一套**可以复核的判断生成流程**。急着用的人可以只走第一遍，但请务必把第二、第三遍留给真正要做决定的那几篇——判断的分量，从来都是在核对出身与划清边界之后才有的。

## 三、主题簇阅读路径

不必从乾卦顺序读起。以下路径按实际成文情况列出，簇内每卦均可独立成篇，箭头表示建议顺序：

- **起步线**：屯 → 蒙 → 需 → 讼（创业、开蒙、等待、止损；再接小畜、大畜、颐、蹇、升、渐）
- **组织领导线**：临 → 师 → 比 → 谦（感通、动员、结盟、谦抑；再接咸、家人、巽、兑、萃、中孚、同人、大有、随、豫）
- **变革转型线**：革 → 鼎 → 蛊 → 损 → 益（换轨、立制、治旧弊、成本与收益的承担方向；再接夬、解、噬嗑、贲、井、涣、节、睽）
- **处境判断线**：乾 → 坤 → 泰 → 否 → 既济 → 未济（时位、承载、通塞、完成与未完成；再接剥、复、无妄、大过、坎、离、遁、大壮、晋、明夷、困、震、艮、归妹、丰、旅、小过）
- **消长主线**：临 → 泰 → 否 → 剥 → 复（长、平、消、剥、复——优势窗口的完整生命周期）
- **资源线**：损 → 益 → 小畜 → 大有 → 丰（减损、增益、小蓄、大有、盛极）
- **艰难线**：困 → 蹇 → 坎 → 明夷（穷、阻、险、晦明——四种难法，四种守法）
- **进退线**：遁 → 大壮 → 晋 → 渐（退的梯度、盛的节制、进的台阶）
- **聚散线**：萃 → 涣 → 同人 → 家人 → 睽（聚人、散而后聚、同盟、内部治理、乖离求同）
- **信与度**：中孚 → 小过（孚是信，过是度，一对双尺）

想精读一个主题，就沿对应线走；想核对一处结构，直接用第六节的关联跳转。每条线走到末端，不妨做一次小复盘：把线上各卦的"实践清单"摊在一处，看它们互相印证还是互相打架——打架的地方，往往就是条件边界没划清的地方。

## 四、血统标注怎么读

每条现代判断都带血统标签，这是全书最重要的精度装置：

- **[转译]**：原文有对应结构，古今之间是结构映射。例：19 临"刚浸而长"→ 量变积累期的形势判断。
- **[引申]**：原文无直接对应，是借其结构向现代问题延伸；需要换主体的也在此列。例：19 临"至于八月有凶"→ 反转预案与优势窗口续期（"凶"还原为条件后果）；"容保民无疆"→ 公共服务的普惠逻辑（主体由君子换为组织责任）。
- **[不可通约]**：原文与现代价值冲突，或原文根本无此维度，明确留白。例：循环史观与历史唯物主义相抵；君子—小民框架中无个体权利位置——这类地方宁可空着，不做"贯通"。

读法建议：把 [引申] 当假说看，把 [不可通约] 当边界看，只把 [转译] 当文本证据看。

## 五、现代实例与 notes/examples.md 索引

`notes/examples.md` 是全部实例的集中索引（卦、实例名、一句话、来源链接）。正文实例统一四行格式：事件经过 → 对应哪个结构 → 可核验的边界/条件 → 来源 URL。

**定位务必摆正：实例是检验材料，不是预测论据。** 它们用于检验结构转译是否成立、边界条件是否可辨，不构成对任何组织或个人的评价，更不能反过来当"卦灵不灵"的证据。数字口径有分歧处均标区间或"待核"；来源 URL 逐条实测存档，反爬源均配权威备选。

用法：读完一篇觉得结构可疑，去索引里找同卦实例，先读"可核验的边界"一行，再读事件本身——顺序反了容易变成看故事。

## 六、GLOSSARY 用法

`GLOSSARY.md` 收术语对照（概念 — 现代对应 — 类型 — 出处卦），随各期回填。遇到"综卦""相错""消长主线""血统""动爻"这类工程内术语，先查表再读正文；发现表里没有的新术语，以正文定义为准并欢迎回填。

## 七、硬边界与失败模式自检清单

三条硬边界（全文遵守，读者可用以核查任何一篇）：

1. **不替代实证**——只生成假说、提示盲区，结论靠调研数据。
2. **不预测吉凶**——原文"吉""凶"只作训诂对象，转译还原为条件后果；出现面向未来的判断即为越界。
3. **不可通约处留白**——现代价值无对应结构处标注 [不可通约]，宁可空着。

两个失败模式（读与用都适用）：

- **新瓶装旧酒**：术语换了，思想没动。自检：这句是不是只把爻辞改写成了现代汉语？
- **旧瓶装空酒**：大谈博大精深，落不到可执行判断。自检：这段有没有一条可执行、可证伪的判断？

每读完一篇，用这两问各扫一遍；两问都过，这篇才算读懂了。若发现本书某处违反三条硬边界或落入两个失败模式，以硬边界为准绳指出它——这套方法允许被自己的纪律纠正，这正是它区别于玄学的地方。
