# 02 / 坤 / ䷁（坤上坤下）

> 主题：承载配合与底线。

## 一、训诂

### 原文

**卦辞**：坤，元亨，利牝马之贞。君子有攸往，先迷后得主，利。西南得朋，东北丧朋。安贞吉。

**彖曰**：至哉坤元，万物资生，乃顺承天。坤厚载物，德合无疆。含弘光大，品物咸亨。牝马地类，行地无疆，柔顺利贞。君子攸行，先迷失道，后顺得常。西南得朋，乃与类行；东北丧朋，乃终有庆。安贞之吉，应地无疆。

**象曰**：地势坤，君子以厚德载物。

**爻辞**：
- 初六：履霜，坚冰至。象曰：履霜坚冰，阴始凝也。驯致其道，至坚冰也。
- 六二：直，方，大，不习无不利。象曰：六二之动，直以方也。不习无不利，地道光也。
- 六三：含章可贞。或从王事，无成有终。象曰：含章可贞，以时发也。或从王事，知光大也。
- 六四：括囊，无咎无誉。象曰：括囊无咎，慎不害也。
- 六五：黄裳，元吉。象曰：黄裳元吉，文在中也。
- 上六：龙战于野，其血玄黄。象曰：龙战于野，其道穷也。
- 用六：利永贞。象曰：用六永贞，以大终也。

**文言（节引）**："积善之家必有余庆，积不善之家必有余殃……其所由来者渐矣，由辩之不早辩也。""直其正也，方其义也。君子敬以直内，义以方外。""地道无成而代有终也。""君子黄中通理，正位居体，美在其中，而畅于四支，发于事业。"

### 关键字词

- **坤**：《说卦》"坤，顺也"。取象为地。本卦讲**顺承、厚载、含藏**之德。"地势坤"言地之势顺承而不倾（王弼大意：地形不顺，其势顺）。
- **利牝马之贞**：牝马，母马——柔顺而能行远（顺而健）。坤之"贞"不是强硬守固，是**柔顺而持续地守正**。与乾之贞（刚健守正）对举。
- **先迷后得主**：抢先主导则迷，随后配合则得其所主、得其常道（象传：先迷失道，后顺得常）。"得主"一说得主导者/依归，一说得常道；两解并存。
- **西南得朋，东北丧朋**：依文王八卦方位，坤居西南（阴方）。主流注疏以"朋"为朋类（同类、伙伴）：西南得同类相助，东北离其类而从阳（与乾合），故"乃终有庆"。另有一训"朋"为贝币（十贝为朋），得丧为财货之象——细节存疑，此处取朋类义。
- **安贞吉**：安于守正则吉——坤德以"安"为要。
- **坤厚载物，德合无疆**：厚，容量大；载物，承载万物。**承载力与容量**是坤的核心意象。
- **履霜，坚冰至**：履，践踏。踩到霜，便知坚冰将至。象传"阴始凝也。驯致其道，至坚冰也"——顺着趋势推演，微兆会发展成大势。文言引申为防微杜渐："其所由来者渐矣，由辩之不早辩也"（坏事由渐而至，在于不及早辨察）。
- **直，方，大，不习无不利**：直，内正（文言："直其正也"）；方，外有规范（"方其义也"）；大，广博；不习，不假修习、不刻意造作而自无不利（地道自然光大）。**内直外方**是坤的成德路径。
- **含章可贞**：含，内藏；章，文采、才华。有才华而内含不炫，守正待时。"以时发也"——到时机才发挥。
- **或从王事，无成有终**：参与大事而不居功（无成），却能善终（有终）。文言："地道无成而代有终也"。注意：此爻古义建立在**君臣（夫妻）尊卑框架**上，现代转译须换主体（见下），框架本身 [不可通约]。
- **括囊**：括，结扎。扎紧口袋——**缄口收缩、谨慎不发**。无咎无誉：不获咎也不获誉，是风险期的合理状态。
- **黄裳元吉**：黄为中色（土居中），裳为下衣（衣上裳下）——**居中而守其分**。文言"黄中通理，正位居体……发于事业"：内在通达，位置得体。
- **龙战于野，其血玄黄**：阴盛至极而与阳争，于野（失去配合的位置）相战；玄（天色）黄（地色）相杂——**两败俱伤、秩序崩坏**。象传"其道穷也"：顺承之道走到尽头才会这样。
- **用六，利永贞**：坤六爻皆老阴、整体变通之辞。永贞，长久守正；"以大终也"——以大地之德成就最终结果。

## 二、语境

这一卦处理的问题：**不在主导位的人（副手、平台、承载方、协作方、基础服务）怎么自处——怎么顺而不失其正、怎么承载而不崩、什么时候收紧、底线在哪里。**

落到现代实际：团队副手与骨干、平台与基础设施、乙方与协作方、组织里的"地基型"角色。核心矛盾：配合者容易滑向两个极端——**抢跑越位**（先迷）或**无原则顺从直到崩坏**（龙战于野）。坤卦给的是第三条路：内直外方、含章待时、有清楚的底线。

## 三、结构

| 易学结构 | 抽出的关系结构 |
|---|---|
| 地势坤、厚德载物 | 承载方的容量决定系统的稳定性；承载力是硬约束 |
| 利牝马之贞 | 配合者的守正方式：柔顺 + 持续行动力（顺而健） |
| 先迷后得主 | 配合者的主动性边界：不抢主导，但必须在位 |
| 履霜坚冰至 | 趋势预警：微兆→推演→预防（量变到质变的古典表述） |
| 直、方、大 | 内正 + 外规范 + 格局 = 配合者的立身结构 |
| 含章、以时发 | 韬晦与出场时机：有实力不炫，到点才用 |
| 括囊 | 风险期收缩：少说少错，先求无害 |
| 黄裳 | 居中守分：位置感与得体 |
| 龙战于野，其道穷 | 底线失守的终局：顺从走到尽头是系统性对抗 |
| 用六利永贞 | 长期主义：承载是无限期承诺，故须可持续 |

## 四、现代转译（新断词）

> **厚德载物 = 组织/平台的承载力**：能承载多少人、多少事、多少错误，是硬指标，不是美德表演。承载力不够而硬扛，就是把"厚德"变成崩盘。[转译：坤厚载物、德合无疆；引申：承载力可测量为现代注入]

> 配合者的位置法则：**不抢跑，也不缺位**。抢先主导则迷失方向，但"后得主"不是被动等待——是到位、接住、完成（柔顺利贞，牝马行地无疆）。[转译：先迷后得主、利牝马之贞；"配合"由人身顺从换为契约协作，标注引申]

> **见微知著是义务**：踩到霜就该想到坚冰，微兆出现就要推演趋势、及早辨察——坏事都是"由来者渐"，败于不及早分辨。[转译：履霜坚冰至、由辩之不早辩也；与 01-乾"夕惕若厉"同构]

> 立身结构是**内直外方**：内心正直（敬以直内），行为有规范（义以方外），格局要大；不刻意造作也行得通。[转译：直方大、不习无不利]

> 有实力**含得住**，到时机才发挥（含章可贞，以时发也）；参与大事不居功、但要把事办完办成（无成有终）。[转译：六三；"不居功"保留，"臣道、妻道"的尊卑框架处 [不可通约]，留白并换主体]

> 风险期学会**扎口袋**：少表态、先收缩、求无害；"无誉"是可接受的代价。[转译：括囊，慎不害也]

> 居中守分、把位置做对（黄裳）；但**顺从有底线**：把配合做成无原则服从，终局是"龙战于野"——压抑到极点的对抗，两败俱伤，其道穷也。底线要在"履霜"时就写明，而不是等到"战于野"才喊。[转译：上六；引申：底线条款为现代注入]

**双向张力**：现代协作理论给"厚德载物"分辨率——平台容量、冗余设计、心理承载（团队 burnout）都是可测变量；"括囊"照出现代病：鼓励人人发声的文化里，风险期的沉默常被误判为无能，而坤卦给沉默以正当位置。反过来，"龙战于野"照出现代协作的暗面：任何把"配合"做成单向服从的结构，都在积累系统性风险。

## 五、实践清单

- **可执行判断**：
  1. 先测承载力再承诺：人、钱、注意力三项容量核对，超载即拒绝或扩容（厚德载物的量化）。
  2. 配合位岗位写清楚"不抢跑"与"不缺位"两张清单：哪些事不越位决策，哪些事必须主动接住。
  3. 微兆台账：每月列出三个"霜"（早期信号），逐条推演"坚冰"（后果），定预防动作（履霜坚冰至）。
  4. 立身标准：内心准则（敬以直内）与外部规范（义以方外）各写三条，作为行事自查。
  5. 韬晦与出场：有实力不急于表现，设定"以时发"的触发条件（时机指标），到线才用。
  6. 风险期收缩预案：什么信号出现就"括囊"（停表态、收缩战线、保安全）。
  7. **底线条款**：配合者预先写明不可退让的三条底线（原则、健康、法律），并让协作方知情；触线即启动"得主/换位"程序，而不是忍到"战于野"。
- **适用条件**：自己确在配合位/承载位；主导方方向正当（"得主"的前提是所随之主不恶）。
- **反例与边界**：
  - 配合滑向讨好：无原则顺从是"甘临"（19-临）的同病，不是坤德。
  - 承载滑向无边界：不设容量的"厚德"是 burnout 与崩盘前奏，"安贞"以自我保存为前提。
  - "先迷后得主"不能被用来压制正当的主动性：协作中的专业异议属"直方"，不是"抢跑"。
  - 所随之主方向不正时，坤卦不提供答案（原文框架是随明主）——此处现代补入：**契约自由与退出权**在原文中无对应结构，标注 [不可通约]，由现代法治价值补入。
  - "龙战于野"不是鼓吹对抗：它是**失序的后果描述**，用途是警示及早设底线，不是预演斗争。
- **验证方式**：容量指标（负载率、冗余度）、微兆台账的预防动作执行率、底线条款触线处理时长、协作方对配合边界的知晓度、无原则顺从事件的复盘数。

### 现代实例

**实例：蒂姆·库克 1998 年入主苹果供应链的"厚德载物"（1998 起）**
- 事件经过：1998 年，乔布斯亲自招募时任康柏副总裁的蒂姆·库克加入苹果任全球运营高级副总裁，当时苹果濒临破产；库克重整供应链——关闭自有工厂、转向全球代工网络、对关键元件（如闪存）做长期预付锁供——把运营做成"低成本、高可靠"的承载底座；他先后任 COO，2011 年接任 CEO。
- 对应结构："厚德载物"的现代样本——配合位（COO/运营）不抢产品之光，把**承载力**（交付、成本、可靠性）做到极限；"直方大"（标准化、规范化的运营体系）；"黄裳"（居中守分的副手姿态，主角是产品与愿景）。
- 边界与条件：此例只核验"承载—配合"结构，不评价其任 CEO 后的决策；供应链细节以 Britannica 与苹果官方口径为准；承载力的价值依赖主导方向正当（"得主"前提）。

## 六、与其他卦的关联

- **01 乾**：乾坤一体——乾给方向与动力，坤给承载与配合；"自强不息"与"厚德载物"成对使用。
- **03 屯**：屯卦"利建侯"是坤卦"得主"问题的正面解：先确立结构，配合才有依托。
- **04 蒙**："果行育德"与"直方大"同属成德路径。
- **19 临**："容保民无疆"直接承坤德（容、保皆坤之用）。
- **12 否 / 11 泰**：上下不交（否）与上下交（泰）是"得主/失主"关系的组织化展开。
- **15 谦**：坤之"含章"在谦卦成为主题（有功而不伐）。
