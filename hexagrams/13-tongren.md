# 13 / 天火同人 / ䷌（乾上离下）

> 主题：协作与同盟——"同人于野亨利涉大川"（开放协作可济大险）、"同人于门无咎/同人于宗吝"（于野＝开放、于宗＝小圈子）、"伏戎于莽升其高陵三岁不兴"（暗伏争胜而不果）、"乘其墉弗克攻吉"（知难而返）、"同人先号啕而后笑大师克相遇"（先隔后合）、"同人于郊无悔"（未得大同亦无悔）（语境="协作与同盟：圈子开多大、争什么让什么"；与 08 比（亲比）、45 萃（聚人）、20 观（示同）衔接）。

## 一、训诂

### 原文

**卦辞**：同人于野，亨。利涉大川，利君子贞。

**彖曰**：同人，柔得位得中，而应乎乾，曰同人。同人曰：同人于野，亨，利涉大川，乾行也。文明以健，中正而应，君子正也。唯君子为能通天下之志。

**象曰**：天与火，同人。君子以类族辨物。

**爻辞**：
- 初九：同人于门，无咎。象曰：出门同人，又谁咎也。
- 六二：同人于宗，吝。象曰：同人于宗，吝道也。
- 九三：伏戎于莽，升其高陵，三岁不兴。象曰：伏戎于莽，敌刚也。三岁不兴，安行也。
- 九四：乘其墉，弗克攻，吉。象曰：乘其墉，义弗克也。其吉，则困而反则也。
- 九五：同人，先号啕而后笑，大师克相遇。象曰：同人之先，以中直也。大师相遇，言相克也。
- 上九：同人于郊，无悔。象曰：同人于郊，志未得也。

### 关键字词

- **同人**：同，会合、协同（《说文》"同，合会也"）；人，众人。**与人协同、聚人成事**。卦象天与火（乾上离下）——**火性炎上、与天同向**（"天与火"，注疏或释"与"为亲与：天在上、火亦炎上，其性相同），故名同人。结构义：**协作与同盟——找同道、成共同、划圈子**。
- **同人于野**：野，邑外曰郊、郊外曰野（《尔雅》系统），**离人群中心最远的旷野**，喻最开放、最无边界的场合。**在"野"上协同，亨通，利涉大川**。彖传"乾行也"（乾健之行）、"**唯君子为能通天下之志**"（只有正者能贯通天下人的心志）。结构义：**协作的开放度决定容量——于野（开放结盟）才装得下天下之志**。
- **文明以健，中正而应**：下离为文明，上乾为健；六二柔中正、应九五刚中正。结构义：**协作的质地＝表达清楚（文）＋执行力强（健）＋中正呼应**。
- **类族辨物**（象）：类族，分类族属；辨物，分辨事物。注疏大意：**求同不废辨异**——把人与物按类分辨，同其所当同。结构义：**协作的前提是分类清晰**：同道（类）、非同道（辨），先辨后同，否则"同"是糊涂账。
- **同人于门**：门，家门/门庭；初九"出门同人"（象传：出门同人，又谁咎也）。**在门口（半开放）与人协同**——比"于野"窄、比"于宗"宽，无咎。结构义：**从自家门口开始结盟**：先邻近、先小圈试水，无过。
- **同人于宗**（宗）：宗，宗党、同宗、小圈子（注疏或指同姓宗族，或指党派门户）。**只在小圈子里协同＝吝**（吝道也：走向狭隘）。结构义：**圈子化的协作有天花板，且有排他代价**——"宗"里的人越亲，"宗"外的人越远。
- **伏戎于莽，升其高陵，三岁不兴**：戎，兵戎；莽，草莽；高陵，高地；三岁不兴，多年不成。**把兵埋在草莽里、登上高处窥望，多年也成不了事**。象传"敌刚也"（所敌者刚强）、"安行也"（怎能行得通）。结构义：**暗中备争、伺机争胜的协作是假协作**——伏戎于莽式的小动作，对上刚强的对手（或对内同盟的正当性）根本走不通。
- **乘其墉，弗克攻**（墉 yōng）：墉，城墙；乘墉，登上城墙（临城欲攻）；弗克攻，攻不下来。象传"**义弗克也**"（于义不能克）、"**其吉，则困而反则也**"（其吉在于受困而返于法则）。结构义：**攻不下就收手，返于规则即是吉**——协作破裂时知难而返、退回规则线，比硬攻体面。
- **同人先号啕而后笑**（号啕）：号啕，大哭。**先大哭、后大笑；大军最终会师**（大师克相遇）。象传"以中直也"（以中正直道）、"言相克也"（相克＝相胜其难而会合）。结构义：**真同盟的典型时间线是先隔后合**——冲突、拆伙、误会（号啕）在前，会师（笑）在后；判定标准是"中直"（动机中正），不是过程的顺滑。
- **同人于郊，无悔**：郊，邑外（近于野、未至野）。**在"郊"上协同（未达最开放），志未得也，但无悔**。结构义：**同盟没做到最大，也不必悔**——于郊是次优解，够用即可。
- **"同人"与"大有"**：同人（13）与大有（14）互综（卦画颠倒）——**同人是"聚人"（把人聚到一起），大有是"聚物"（把资源聚到一起）**；先同人而后大有。

## 二、语境

这一卦处理的问题：**协作与同盟——圈子开多大、争什么让什么。**——开放度的刻度（于门→于郊→于野）、圈子化的代价（于宗吝）、假协作的识别（伏戎于莽）、破裂时的收手（乘墉弗克攻）、真同盟的时间线（先号啕后笑）、次优解的接受（于郊无悔）。

落到现代实际：行业联盟与标准共同体、开源社区、公司间战略合作、团队内部的跨部门协作、国与国的多边机制。本卦给"协作"立了三条主线：**一、圈子越开放容量越大，但开放要从"门"走到"野"（逐步而非一步）；二、暗藏争胜的同盟是假同盟（伏戎）；三、真同盟是先隔后合的，判定看动机中正（中直）不看过程顺滑**。

## 三、结构

| 易学结构 | 抽出的关系结构 |
|---|---|
| 天与火（性同而上） | 协作的根基：方向一致（同向）才谈同人 |
| 同人于野 | 开放度=容量：于野（无边界）才通天下之志 |
| 文明以健，中正而应 | 协作质地：表达清楚＋执行强＋中正呼应 |
| 类族辨物 | 先辨后同：分类清晰，同其所当同 |
| 同人于门 → 于郊 → 于野 | 开放度刻度：半开放→次开放→全开放，逐档推进 |
| 同人于宗，吝 | 小圈子化：亲密度换容量，且排他 |
| 伏戎于莽，三岁不兴 | 假协作：暗藏争胜者，对刚不果 |
| 乘其墉弗克攻 | 破裂收手：攻不下则返于法则 |
| 先号啕而后笑 | 真同盟时间线：先隔后合（以中直也） |
| 唯君子为能通天下之志 | 贯通多方的条件：动机与规则中正 |

## 四、现代转译（新断词）

> **协作的容量由开放度决定**（同人于野，亨，利涉大川；通天下之志）：把圈子开到"野"（公开、无门户、进出自由）才能通天下之志、济大险（利涉大川）；开在"宗"（同门、同派、同利）里，再亲也只装得下小局。**于野不是姿态，是容量设计**。[转译：卦辞、彖传]

> **开放要逐档走**（于门→于郊→于野）：从自家门口（试点伙伴）到邑外之郊（行业圈）再到旷野（公开标准/开放社区），一档一档开；**跳档硬开（小团队直接宣布"开放生态"）容易散架**。[转译：初九、上九、卦辞；三爻合观]

> **小圈子化是协作的慢性病**（同人于宗，吝）：圈内互信成本低、圈外交易成本高，久之"宗"就成了天花板和墙——**"吝"不是报应，是结构后果：圈子越亲，圈子外越远**。[转译：六二、象传]

> **先辨后同**（君子以类族辨物）：求同之前先分类——谁是同道（类）、谁是伙伴、谁是对手（辨）。**不辨物的"同"是糊涂账**：把对手当同人、把搭便车者当同道，最后号啕的是自己。[转译：大象]

> **暗藏争胜的同盟是假同盟**（伏戎于莽，升其高陵，三岁不兴）：签着合作协议、暗里伏着"戎"（抢赛道、挖人、备背刺），登高窥望等着对方失手——**"三岁不兴"是结构后果：所敌者刚（对方不弱），暗动作根本成不了事**。识别标志：一边同人一边备战。[转译：九三、象传]

> **攻不下就返于法则**（乘其墉，弗克攻，吉；困而反则也）：合作破裂、翻墙攻城式的撕扯（抢市场、抢人、互诉）攻不下来时，**收手回到规则线（合同、章程、竞业边界）反而是吉**——"吉"不来自胜利，来自"反则"。[转译：九四、象传]

> **真同盟是先隔后合的**（同人，先号啕而后笑，大师克相遇）：不要因为冲突（号啕）就宣判同盟失败——**判定标准是"中直"（动机与规则是否中正），不是过程顺滑**；中直的分歧终会"克相遇"（会师），不中直的和气早晚会拆。[转译：九五、象传]

> **同盟没做到最大也不必悔**（同人于郊，无悔）：于郊（次开放）是次优解；"志未得"（没通天下之志）但无悔——**够用的同盟好过勉强的"于野"**（开放度超出治理能力的联盟，散得更快）。[转译：上九、象传]

> **"通天下之志"的君子主体须换为"各方"**；周代"大师克相遇"的军争内容不移植，只取"先隔后合"的结构义；"戎/莽/墉"的城邦攻战语境与现代竞争法、国际法规范**留白**。[不可通约]

**双向张力**：现代网络理论与制度经济学给了"同人"分辨率——**网络效应、开放标准（RFC 式治理）、交易成本、可信承诺**都能量化"于野/于宗"的容量差；而同人照见现代病：**"生态"话术下的宗派化**（嘴上于野、实际于宗：站队、二选一、潜规则）、**协议下的伏戎**（合作备忘录后面藏着竞对清单）、**把冲突当失败**（一吵就散，不懂"先号啕而后笑"）。反过来，"类族辨物"给开放运动补一课：**没有辨物的开放是被吞噬**——开放社区也要有准入、分类与规则，否则"通天下之志"变成"被天下之人通吃"。

## 五、实践清单

- **可执行判断**：
 1. 开放度定位：给自己的协作圈标位置（门/郊/野），写明这一档的进出规则，升档条件达成再升档。
 2. 宗病体检：每季统计"合作方里有多少来自圈子外"——占比持续下降即"同人于宗"，强制引入圈外伙伴。
 3. 类族辨物表：每个联盟先做四栏表（同道/伙伴/对手/待辨），逐栏出策略，再谈"同"。
 4. 伏戎扫描：合作协议签署后逐条排查"暗备争胜"条款与行为（独家锁人、暗挖墙脚、备用竞品），有则先拆伏戎再合作。
 5. 反则条款：所有合作协议写明破裂时的"回规则线"路径（争议解决、退出、竞业），破墙强攻的成本算清再动（乘墉弗克攻）。
 6. 号啕预算：重大同盟提前给冲突期留时间与情绪预算（3–6 个月的磨合期），以"中直"（动机中正）复核而非顺滑度评判。
 7. 于郊止步：治理能力不足时主动停在"于郊"，不硬撑"于野"。
- **适用条件**：需要多方协作的场景（联盟、开源、标准、跨部门、多边机制）；存在可辨识的同道/对手；有规则线可回。
- **反例与边界**：
 - "于野"不等于无条件开放：没有准入与规则的开放会被"伏戎"者利用；类族辨物是于野的前提而非反面。
 - "先号啕"不为烂同盟背书：判定看中直——动机不正、规则不公的冲突不是"必经阶段"，是散伙预兆。
 - "弗克攻"不禁止正当维权：回到规则线（合同、法律）正是"反则"，反则≠软弱。
 - "同人于宗，吝"不否定小团队亲密：亲密度本身是资产，病在**把宗当作协作的上限**。
 - 本卦不预测同盟成败时点：合散时间是调研问题，本卦只给"开放度—辨物—中直"的结构。
- **验证方式**：圈外伙伴占比（宗病指标）、合作方进出频率（开放度实测）、伏戎条款清零率、破裂回规则线执行率（对簿 vs 协商解决比）、同盟冲突期留存率（先号啕后笑的兑现率）——五项可季度测量。

### 现代实例

**实例 1：《阿尔忒弥斯协定》——"同人于野"的开放结盟（2020 起）**
- 事件经过：2020-10-13，美国国务院与 NASA 联合澳大利亚、加拿大、意大利、日本、卢森堡、阿联酋、英国共 8 国创始签署《阿尔忒弥斯协定》（Artemis Accords），为月球、火星探测立下"和平、透明、互助、公开科学数据"等实践原则；协定**不设排他门槛、持续吸纳签署方**（2025-09 NASA 公告称 56 国签署、约占全球国家近 30%；2026 年又迎土耳其等新签署方，媒体口径 61 国）。
- 对应结构："**同人于野，亨，利涉大川**"——以公开原则（而非排他军事同盟）立约、进出开放、共同涉"大川"（深空大险）；"**文明以健，中正而应**"——原则成文（文明）＋任务执行（健）＋各国对等呼应；"**类族辨物**"——按原则（和平、透明、数据公开）辨识同道，同其所当同。
- 可核验的边界/条件：2020-10-13 八方创始签署与原则清单以 NASA/国务院官方口径为准；签署方数量随时间增长（56 国为 2025-09 NASA 口径、61 国为 2026-01 媒体口径），本文标时点不精算；协定为非约束性政治承诺（不等于条约义务）；本例只核验"开放结盟—原则辨物"结构，不构成对任何国家政策的评价（硬边界 1、2）。
- 来源：[NASA 官方（HTTP 200，含 8 创始国与原则）](https://www.nasa.gov/organizations/oiir/artemis-accords/nasa-boosts-open-science-data-sharing-with-artemis-accords/) / [NASA 新闻稿（HTTP 200，56 国口径）](https://www.nasa.gov/news-release/nasa-international-partners-deepen-commitment-to-artemis-accords/)

**实例 2：微软加入 Linux 基金会——"先号啕而后笑"的先隔后合（2016）**
- 事件经过：2016-11-16，微软在纽约 Connect() 开发者大会上宣布加入 Linux 基金会并成为**白金会员**；Linux 基金会新闻稿称微软已成为领先的开源贡献者之一。此前二十年微软与 Linux 社区是公开敌对关系（"Linux 是癌症"时代的许可证战、专利诉讼阴影），2014 年纳德拉上任后转向"Microsoft loves Linux"、.NET 开源、Azure 大规模支持 Linux，最终以入会"会师"；同场谷歌加入 .NET 基金会，双方阵营交叉互入。
- 对应结构："**同人，先号啕而后笑，大师克相遇**"——二十年敌对（号啕）之后以共同利益与共同规则（开源许可证、云生态）会师（笑），"**以中直也**"（动机中正：商业利益对齐＋对社区规则的真实遵守，故可合）；"**乘其墉，弗克攻，吉**"的反向——微软早年攻不下的开源"城墙"（强推自有标准）转为"反则"（加入对方规则线：GPL、基金会治理）后反而成事；"**同人于野**"——加入的是开放式治理共同体（基金会），非排他联盟。
- 可核验的边界/条件：入会时间与白金会员身份以 Linux 基金会 2016-11-16 新闻稿与微软官方中文新闻稿口径为准；"二十年敌对""微软爱 Linux"为业界通述的历史脉络（标志性言论的具体措辞另有版本，标待核）；本例只核验"先隔后合—反则成事"结构，不构成对微软或开源运动的评价（硬边界 1、2）。
- 来源：[Linux 基金会官方新闻稿（HTTP 200）](https://www.linuxfoundation.org/press/press-release/microsoft-fortifies-commitment-to-open-source-becomes-linux-foundation-platinum-member) / [微软中国官方新闻稿（HTTP 200，同场谷歌加入 .NET 社区）](https://news.microsoft.com/zh-cn/%E5%BE%AE%E8%BD%AF%E5%8A%A0%E5%85%A5-linux-%E5%9F%BA%E9%87%91%E4%BC%9A%E5%85%B1%E5%BB%BA%E5%BC%80%E6%BA%90%E7%94%9F%E6%80%81%EF%BC%8C%E5%B9%B6%E5%AF%B9%E8%B0%B7%E6%AD%8C%E5%8A%A0%E5%85%A5-net/) / [OSCHINA（HTTP 200，备选源）](https://www.oschina.net/news/79105/)

## 六、与其他卦的关联

- **08 比（亲比）**：**比是"亲比"（以信相亲、显比立约），同人是"求同"（以志相合、于野开圈）**——比讲关系的粘性（原筮尽调、失前禽），同人讲圈子的容量（于野/于宗）。先比后同人：先有互信的粘性，才有开放的容量。
- **45 萃（聚人）**：**萃聚人以"庙"（正当性中心），同人聚人以"志"（通天下之志）**——萃靠共同的仪式与中心凝聚（王假有庙），同人靠共同的方向与规则凝聚（文明以健）；聚而不正（有孚不终）在萃成乱萃，在同人成"伏戎"。
- **20 观（示同）**：**观是"示"（示范使人同），同人是"合"（结盟使事成）**——观"下观而化"给出同人的正当性来源：先把示范做出来，再谈"同"；无观之同人是空约。
- **14 大有（互综）**：**同人—大有互综：同人聚人、大有聚物**——同人把志同者聚到一起，大有把资源聚到一起并治理之；先同人（人合）而后大有（物聚），反过来"大有"之后更需要"同人"（资源引来的人要以志再聚）。
- **13/08/45/20 聚人线**：比（亲）→ 萃（聚）→ 同人（合志）→ 观（示同）四卦合成"聚人线"：粘性、中心、方向、示范，缺一即散。
- **59 涣（聚散）**：涣"涣群涣丘"讲拆散小圈子聚成大丘，正对同人"同人于宗，吝"——**涣其群即去宗，涣有丘即于野**。
