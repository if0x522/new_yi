# 04 / 蒙 / ䷃（艮上坎下）

> 主题：教育启蒙。

## 一、训诂

### 原文

**卦辞**：蒙，亨。匪我求童蒙，童蒙求我。初筮告，再三渎，渎则不告。利贞。

**彖曰**：蒙，山下有险，险而止，蒙。蒙亨，以亨行时中也。匪我求童蒙，童蒙求我，志应也。初筮告，以刚中也。再三渎，渎则不告，渎蒙也。蒙以养正，圣功也。

**象曰**：山下出泉，蒙。君子以果行育德。

**爻辞**：
- 初六：发蒙，利用刑人，用说桎梏，以往吝。象曰：利用刑人，以正法也。
- 九二：包蒙，吉。纳妇，吉。子克家。象曰：子克家，刚柔接也。
- 六三：勿用取女，见金夫，不有躬，无攸利。象曰：勿用取女，行不顺也。
- 六四：困蒙，吝。象曰：困蒙之吝，独远实也。
- 六五：童蒙，吉。象曰：童蒙之吉，顺以巽也。
- 上九：击蒙，不利为寇，利御寇。象曰：利用御寇，上下顺也。

### 关键字词

- **蒙**：《序卦》"蒙者，蒙也，物之稚也"——蒙昧、幼稚，物生之初未明之态。卦象山下有泉（水始出而未成流）、山下有险（险而止）——**幼稚而不知所往**的状态。朱熹《本义》大意：蒙，昧也，物生之初蒙昧未明。
- **匪我求童蒙，童蒙求我**：匪通"非"。不是教育者去求蒙昧者，而是蒙昧者来求教。象传"志应也"——**教育成立的前提是双方意向相应**：学习者的主动求教。
- **初筮告，再三渎，渎则不告**：本为占筮语（初次占筮则告，反复占筮则亵渎而不告）。本工程弃用占筮功能，取其结构义：**求教的态度决定信息供给**——诚心求问则倾囊相告，轻慢反复则降级响应（沟通成本定价）。此处只作训诂与结构转译，不涉占验。
- **利贞**：教育要守正——目标与手段都须正当。
- **山下有险，险而止，蒙**：坎险在下、艮止在上——遇险而不知所出，止步不前，正是蒙昧的处境。
- **以亨行时中也**：启蒙之亨在"时中"——**适时、适度**（教育时机与分寸）。
- **以刚中也**：九二阳刚居中，为一卦之师位——教育者要有真才与定见（刚），又居中不偏。
- **蒙以养正，圣功也**：启蒙的目的是**养成正道**（正直的品性与判断力），不是灌输知识；此为全卦纲领。
- **山下出泉，果行育德**：泉水始出、未成江河——教育是细水长流。果行育德：以**果决的行动**（知行并进、犯错即纠）培育品德（长期涵养）。
- **发蒙，利用刑人，用说桎梏**：发蒙，启蒙之初。"刑人"存两解：一说刑即刑罚，**以惩戒立规矩**；一说"刑"通"型"，**以典范立型范**（树立榜样）。象传"以正法也"偏重立规矩、正法度之义；两解可并存（立规矩与树典范都是启蒙之初的手段），字源问题存疑不作定论。用说桎梏：说通"脱"，脱去桎梏——规矩的目的是**解除蒙昧的束缚**，不是束缚本身。以往吝：一味急进则困。
- **包蒙，吉**：包，包容。九二阳刚居中，包容众阴——**包容初学者的蒙昧笨拙**是教育者的基本德（好老师不嫌学生笨）。
- **纳妇吉，子克家**：阴阳相应之喻。子克家：克，胜任；子能持家——**受教育者能担当大任**（教育的成果）。象传"刚柔接也"：教与学相接。
- **勿用取女，见金夫，不有躬**：六三之戒。"金夫"即有财势者；不有躬，失其自身。喻：**慕势逐利、心不在学**者，教之无益。象传"行不顺也"。注：原文以"取女"为喻，性别框架是时代局限，转译时换为择徒/择伴原则，框架本身 [引申注记]。
- **困蒙，吝**：困于蒙昧。象传"独远实也"——六四远离阳刚（实），**身边没有师友、没有反馈**，故困。
- **童蒙，吉**：六五以柔居尊位而应九二——**以童蒙自居、虚心求教**（顺以巽也，巽为入、为谦逊），位高而不耻下问，故吉。
- **击蒙，不利为寇，利御寇**：击蒙，严厉惩戒蒙昧。但惩戒有边界：**目的是抵御外寇（防人作恶、护其成长），不是自己变成强寇**（以教为名施暴）。象传"上下顺也"：惩戒得当则上下顺。

## 二、语境

这一卦处理的问题：**教与学的关系怎么成立、启蒙的目标是什么、方法与边界在哪里。**

落到现代实际：学校教育、职业培训、导师带新人、组织学习与知识管理、家长教育、知识产品。本卦几乎是一篇古典教育学：**主动性原则（童蒙求我）、态度定价（初筮告）、养正目标（蒙以养正）、方法双轨（立规矩＋树典范）、环境论（困蒙）、惩戒上限（击蒙）**。

## 三、结构

| 易学结构 | 抽出的关系结构 |
|---|---|
| 山下出泉 / 险而止 | 教育对象的初始状态：幼稚、不知所往 |
| 童蒙求我，志应也 | 学习主动性是教育成立的前提 |
| 初筮告，再三渎 | 求教态度决定信息供给（沟通成本定价） |
| 以亨行时中 | 教育时机与分寸：适时、适度 |
| 以刚中也（九二） | 教育者素质：真才＋定见＋居中不偏 |
| 蒙以养正 | 目标函数：养成正道（判断力与品性），非知识灌输 |
| 发蒙（刑人/说桎梏） | 启蒙之初：立规矩 + 树典范 + 解束缚 |
| 包蒙 | 容错：包容初学者的笨拙 |
| 勿用取女，见金夫 | 择教原则：慕势逐利、心不在学者教之无益 |
| 困蒙，独远实 | 学习环境决定学习效果：缺师友、缺反馈则困 |
| 童蒙（六五） | 位高者更须虚心：以蒙自居是高级学习状态 |
| 击蒙，不利为寇 | 惩戒有上限：以教育之名施暴即失败 |

## 四、现代转译（新断词）

> **启蒙的目标是"养正"**：养成正直的品性与独立判断力，不是灌输结论。一切以"让学生记住答案"为目标的教学，都没过"蒙以养正"这道关。[转译：蒙以养正，圣功也]

> **教育成立的前提是对方来求**（童蒙求我，志应也）：被动灌输是成本最高的无效动作。[转译：卦辞；现代修正：义务教育阶段属公民权利义务关系，与原文私学语境主体不同，此处补入 [引申]——主动性原则改造为"激活求知欲"而非"等学生上门"]

> **求教态度决定信息供给**：诚心一问则倾囊相告，轻慢反复则降级响应——这是沟通成本的定价机制，不是势利。[转译：初筮告，再三渎（占筮形式弃用，仅取结构）]

> 启蒙之初两手都要：**立规矩**（正法度、明确边界）与**树典范**（"刑"一说通"型"，以身作则），且规矩的终点是**解除束缚**（用说桎梏）——规矩若只剩束缚，就是失败的启蒙。[转译：发蒙；"刑人"两解存疑并列]

> 教育者须有**真才与定见且不偏**（刚中），并**包容初学者的笨拙**（包蒙）；教育的成果是受教育者能独当一面（子克家）。[转译：九二]

> **择教/择徒看心不看势**：慕势逐利、心不在焉者教之无益（见金夫，不有躬）；反过来，学习者选导师也同理——只认头衔不认功夫，同样行不顺。[转译：六三；原文性别框架为时代局限，标注引申注记]

> **环境决定学习效果**：困在蒙昧里的人，缺的往往不是努力，是师友与反馈（困蒙，独远实也）——给新人配导师、给学习者建反馈回路，比催努力有效。[转译：六四]

> **位高者更须虚心**：以"童蒙"自居、虚心求教，是高级的学习状态（顺以巽也）；专家型领导不肯再当学生，是组织学习的头号堵点。[转译：六五]

> **惩戒有上限**：惩戒的正当目的只有"御寇"（防止作恶、护其成长），一旦变成"为寇"（以教为名施暴、羞辱、体罚），教育就走向反面。[转译：上九，不利为寇，利御寇]

**双向张力**：现代教育学给"时中"分辨率（维果茨基最近发展区、脚手架理论、形成性评价）；"独远实"照见现代教育盲区——把学习问题都归因于学生动机，忽视反馈环境的缺失。反过来，"童蒙求我"照见现代知识消费的一面：把一切学习困难都推给"用户不主动"，与"果行育德"（教育者的果决行动责任）相矛盾——双向校正后，主动性与行动责任各有边界。

## 五、实践清单

- **可执行判断**：
  1. 教学设计先写目标函数：本课/本项目要"养"的正是什么（判断力、品性、方法），写不出就重做课程设计。
  2. 激活求教：用问题、任务、挑战制造"想问"的状态，而不是单向灌输等提问。
  3. 求教响应分级：认真提问（带上下文、有尝试）即时详答；敷衍重复提问给出自查路径，不代答（初筮告之义）。
  4. 规矩与典范双轨：入门第一课讲清三条规矩 + 一个示范案例；季度检视规矩是否仍在"解束缚"而非"造束缚"。
  5. 导师制：每位新人配导师并设固定反馈节奏（解"困蒙"）；反馈缺失视为组织问题，不归咎个人。
  6. 择徒/择伴标准前置：看投入与品性，不看背景头衔（勿用取女之义）。
  7. 专家轮训：要求各级负责人每年重新当一次学生（六五"童蒙"）。
  8. 惩戒红线：所有惩罚性措施限定于"防作恶、护成长"目的，禁止羞辱与体罚；措施需留痕复核（不利为寇）。
- **适用条件**：教育者确有"刚中"（真才定见）；学习者有基本求教意愿或可被激活；存在反馈通道。
- **反例与边界**：
  - "童蒙求我"不能推导为"学生不学活该"：原文是私学场景，现代教育是公共责任——主动性归学生，行动与设计责任归教育者（双向张力）。
  - "击蒙"不能为体罚正名："不利为寇"是明文上限；任何以严格为名的施暴都是失败模式。
  - "初筮告"不能用于屏蔽批评：轻慢之问与正当质疑是两回事，判据是问题质量与诚敬，不是顺逆。
  - 本卦不含"因材施教何时见效"的预测：教育效果只能以评估数据检验（硬边界 1）。
- **验证方式**：学习者的提问数量与质量、反馈回路响应时长、规矩条目的"解束缚"检视记录、导师配覆盖率、受教育者独立担当案例数、惩戒措施留痕与复核率。

### 现代实例

**实例：可汗学院从"童蒙求我"起步（2004–2008）**
- 事件经过：2004 年 8 月，萨尔曼·可汗应家人之请远程辅导表妹纳迪亚的单位换算（她知识里有"瑞士奶酪式"的漏洞）；求教者增加后，他 2006 年起把辅导录成短课发上 YouTube 供自学节奏观看；2008 年注册为 501(c)(3) 非营利组织，发展为面向所有人的免费课程平台。
- 对应结构："童蒙求我"——教育从**学习者的真实求助**成立（辅导表妹的真问题）；"初筮告"——对认真求教给即时、对症的回应；"蒙以养正"——目标是补上知识漏洞、养成自学节奏，不是灌满结论；从一对一求教到可复制课程，是"包蒙"的规模化。
- 边界与条件：组织注册年份部分来源作 2009（成立/注册口径差异），正文以官方支持页 2008 注册为准并标注分歧；此例只检验"求教—回应—养正"结构，不构成对其教学效果的评价。

## 六、与其他卦的关联

- **03 屯**：《序卦》"物生必蒙"——屯是初生，蒙是幼稚；起步（屯）之后是学习与试错（蒙）。
- **01 乾 / 02 坤**："果行"近乾之健、"育德"近坤之厚——教育是乾坤合用。
- **19 临**："君子以教思无穷"——临卦的教化责任在蒙卦展开为教育方法论。
- **20 观**：观卦讲示范与观摩（观民设教），与蒙卦"树典范"（刑通型）同构。
- **49 革**："大人虎变"即典范先行——教育的身教原则与变革的领导先改同理。
