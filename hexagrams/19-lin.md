# 19 / 地泽临 / ䷒（坤上兑下）

> 本卦为项目首卦，含起卦案例 1 全文（见文末附录）。原文依通行本。

## 一、训诂

### 原文

**卦辞**：临，元亨，利贞。至于八月有凶。

**彖曰**：临，刚浸而长，说而顺，刚中而应，大亨以正，天之道也。至于八月有凶，消不久也。

**象曰**：泽上有地，临。君子以教思无穷，容保民无疆。

**爻辞**：
- 初九：咸临，贞吉。象曰：咸临贞吉，志行正也。
- 九二：咸临，吉，无不利。象曰：咸临，吉，无不利，未顺命也。
- 六三：甘临，无攸利。既忧之，无咎。象曰：甘临，位不当也。既忧之，咎不长也。
- 六四：至临，无咎。象曰：至临无咎，位当也。
- 六五：知临，大君之宜，吉。象曰：大君之宜，行中之谓也。
- 上六：敦临，吉，无咎。象曰：敦临之吉，志在内也。

### 关键字词

- **临**：《说文》"监临也"，本义自上视下、居高面对。《序卦》"临，大也"，取阳刚渐长为大之义。两义并存：本卦既讲**居上临下**的姿态，也讲**势头上行**的阶段。卦象泽上有地（岸高临水），故名临。
- **元亨利贞**：两解并存——一作"四德"解（《文言》：元者善之长，亨者嘉之会，利者义之和，贞者事之干），一作占辞解（大通，宜守正）。本工程取结构义："起势通畅 + 守正"，占断形式本身弃用。
- **刚浸而长**：浸，渐也，阳刚渐渐增长（下二阳爻自下而上长）。这是全卦的时势判断：**量变积累期**。
- **说而顺**：说通"悦"，下卦兑悦、上卦坤顺——愉悦而顺遂的互动结构。
- **至于八月有凶**：注疏有分歧（存两解，见下）。"凶"字彖传自释为"消不久也"——**警示的是反转的必然性**，非预言祸福。本工程按条件句转译：若不预判反转、不及早准备，则阶段性优势将丧失。
  - 一解（朱熹《本义》大意）：自复卦一阳之月数至遯卦二阴之月，历八月而阴长阳消；
  - 一解：夏正八月于卦为观（临之综卦），亦为消长反转之时。
  - 两解共同点：**盛势中蕴含消退，"不久"是结构性的**。
- **咸临**：咸，主流注疏取"感"义（《咸》卦彖"咸，感也"），即以真诚感通临下；另有一训"皆、遍"（普遍施临、无一遗漏）。两解在实践上可并存：感通要真诚，也要覆盖到位。
- **甘临**：甘，甜美、谄媚。以讨好、甜言蜜语临下。象传判"位不当也"——六三以柔居刚位，姿态失当。
- **至临**：至，亲到。亲临现场。象传"位当也"。
- **知临**：知通"智"。以智慧治理，善于用人分权，象传称"大君之宜，行中之谓也"——居上者恰当之举是守中、授权，而非事必躬亲。
- **敦临**：敦，敦厚宽厚。以厚道托底。
- **容保民无疆**：容、保皆容纳养护之义；坤为众，兑为悦——使众人心悦而得养护，取普惠之义。

## 二、语境

这一卦处理的问题：**一个处于上升期、势头正盛的系统（团队、组织、事业），掌权者/管理者应该如何对待下面的人，以及如何对待"好势头本身"。**

落到现代实际：业务扩张期或权力上升期的管理——新官上任、项目顺风期、组织快速增长期。两个陷阱都在卦里点了名：一是临下的姿态（压人、讨好、疏离 vs 感通、到场、授权、托底），二是把顺境当成永久（"至于八月有凶"）。

## 三、结构

| 易学结构 | 抽出的关系结构 |
|---|---|
| 泽上有地 | 居上者面对在下的广大群体；上位者的姿态是本卦主变量 |
| 刚浸而长 | 上升期：优势由量变积累而来，尚未到顶 |
| 说而顺，刚中而应 | 上下互动顺畅 + 中位者有呼应通道 → 组织活力的来源 |
| 初、二皆"咸临" | 上升期的根本功在基层与中层：感通到位则全局皆活 |
| 三甘、四至、五知、上敦 | 管理姿态谱系：讨好型 / 到场型 / 授权型 / 托底型 |
| "至于八月有凶"，消不久也 | 任何阶段性优势都会反转；"势"有保质期 |
| 教思无穷，容保民无疆 | 公共性：教化与养护没有边界（普惠逻辑） |

## 四、现代转译（新断词）

> 事在初起，上升的基础已经形成，势头是通的。此时的关键在最基层的那一环：**以诚待下、以正律己，不靠位置压人**，把人心感通到位，则全局皆活。[转译：刚浸而长、咸临、志行正也]

> 但盛势中要预判反复，及早准备，不能把阶段性优势当成永久。[引申：八月有凶、消不久也——"凶"还原为条件后果，不做未来判断]

> 管理姿态决定成败：讨好下属换不来服从，甜言蜜语掩盖不了位置失当；唯一有效的是一线**到场**、中层**授权**、高层**托底**。[转译：甘临/至临/知临/敦临四爻]

> 下一步事情会转入**立规矩、聚人力**的阶段，成败取决于两条：一是方向与手段守正，二是任用堪当大任的人来主事。[转译：师卦（临之变卦）、容民畜众；"任用堪当大任的人"为转译但主体须由君主换为干部]

> 教化与保障是普惠的，不设边界，不挑对象。[引申：教思无穷，容保民无疆——主体由"君子"换为公共服务与组织责任]

> 盛衰有定数、天道好还式的循环论，与历史唯物主义相抵，本卦"八月有凶"背后的循环宇宙观此处**留白**。[不可通约]

**双向张力**：现代管理学给"咸临"分辨率（真诚沟通、走动式管理、心理安全感是可测的组织变量）；"甘临"照出现代病——用福利讨好代替规则公正、用团建话术代替真实互动，正是"无攸利"的现代版本。而"消不久也"提醒现代组织：增长曲线不是自然律，优势窗口需要主动续期（自我革命），否则"刚浸而长"会走到"龙战于野"式的反转。

## 五、实践清单

- **可执行判断**：
  1. 上升期第一动作是下沉一线：每周固定时间到场接触最基层（至临），不以汇报代替亲临。
  2. 对下沟通以实话与兑现为主，禁止用许诺和姿态讨好换服从（戒甘临）。
  3. 决策者守中授权：把能交给中层的决定交出去，自己管方向与人（知临）。
  4. 对团队托底：出错时担责、困难时兜底（敦临）。
  5. 给每个"顺境项目"写**反转预案**：列出三个"势头会退"的领先指标，按月复核（应对"消不久"）。
- **适用条件**：常态治理、扩张期、组织建设期；上下信息通道尚存（"刚中而应"）。
- **反例与边界**：
  - 应急处置须令行禁止——"以诚待下"非万灵，危机时先纪律后感通（详见 07-shi）。
  - 感通不等于无原则：六三"甘临"正是无原则的失败样本；"既忧之"提示发现姿态失当要立刻纠偏，而非将错就错。
  - 若上位者与基层通道断裂（"应"失灵），本卦清单全部失效，先修通道。
  - 系统已过峰值（非"浸而长"阶段）时，本卦前提不成立，另参 49-革。
- **验证方式**：一线接触频率、跨层级信息失真度、授权决定占比、反转预案触发记录——四项均可月度测量；对照组看推行前后变化。
