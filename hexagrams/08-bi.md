# 08 / 水地比 / ䷇（坎上坤下）

> 主题：亲比与联盟——协作/结盟的方法（原筮尽调、显比、舍逆取顺）。

## 一、训诂

### 原文

**卦辞**：比，吉。原筮，元永贞，无咎。不宁方来，后夫凶。

**彖曰**：比，吉也；比，辅也，下顺从也。原筮元永贞无咎，以刚中也。不宁方来，上下应也。后夫凶，其道穷也。

**象曰**：地上有水，比。先王以建万国，亲诸侯。

**爻辞**：
- 初六：有孚比之，无咎。有孚盈缶，终来有他，吉。象曰：比之初六，有他吉也。
- 六二：比之自内，贞吉。象曰：比之自内，不自失也。
- 六三：比之匪人。象曰：比之匪人，不亦伤乎。
- 六四：外比之，贞吉。象曰：外比于贤，以从上也。
- 九五：显比，王用三驱，失前禽。邑人不诫，吉。象曰：显比之吉，位正中也。舍逆取顺，失前禽也。邑人不诫，上使中也。
- 上六：比之无首，凶。象曰：比之无首，无所终也。

### 关键字词

- **比**：《说文》"密也"，从二人相并——本义**亲近、并列、相依**。《杂卦》"比，乐师忧"；《序卦》"众必有所比，故受之以比"：人众必然互相亲近结伙。卦象地上有水（水行地上、无隙不入、附地而流）——**亲附、渗透、依存**之象。彖传"比，辅也，下顺从也"——亲比即辅助。
- **吉。原筮，元永贞，无咎**：原筮，历来是训诂难点（存两解并列）：
  - 一训"原"为**再、重**（《尔雅》"原，再也"），"原筮"即再筮、反复占问——**结盟前反复考察**；
  - 一训"原"为**本原、推原**（王弼大意：推原占筮之义/求其本原），朱熹《本义》大意取"再筮以自审"。两训共同的结构义是：**结盟要经过反复、审慎的尽职考察**。
  元永贞：元（始/大）、永（久）、贞（正）——**从头到尾守正**，三个字是结盟的长期条件。占筮形式本卦可弃用（本工程不占），保留"反复考察"的结构义。"无咎"还原为条件后果：做到尽调与守正，结盟才不出乱子。
- **不宁方来，后夫凶**：方，方才、并（一说方国）；不宁方来——**不安定的一方才来亲附**（另一读：不宁者方才来求比）。后夫凶：后至者凶（"夫"为语辞或指人；传统解为后来之人/迟到的归附者）。象传"后夫凶，其道穷也"——**亲附有时间性：迟到者无处可去**。此处"凶"转译为条件后果：观望到最后才上车的，位置已被占完、信用已折价。
- **比，辅也，下顺从也**：亲比的结构是**辅助与顺承**——下顺从于上，亲附有主从方向（九五为比之主）。注疏多强调"建万国，亲诸侯"的封建语境；转译须换主体：由王朝封建换为**联盟与协作网络**，标注引申。
- **上下应也**：上下互相呼应——**双向吸引**是亲比成立的条件，不是单向拉拢。
- **地上有水，先王以建万国，亲诸侯**：水土相附，分封万国而亲抚诸侯——**以亲比维系广土众民的治理体系**。"建万国亲诸侯"是联盟拓扑的古典表述：中心节点 + 亲附的分节点。
- **有孚比之**：以信实亲比。**有孚盈缶**：缶，瓦质容器（朴素之器）；盈缶，**信实充满朴素之器**——诚信不靠排场，朴素的容器装得满（一说喻诚中形外；一说缶为乐器，盈缶为乐作而和，存两解，取"诚信充盈于朴素"为结构义）。**终来有他，吉**：终能招来意外之好（他，非分之想之外的额外收获；一说"有他"为有他故/变故而终吉），存两解。
- **比之自内**：亲比发自内心（六二居内卦、柔中得正）。象传"不自失也"——**不因攀附而失掉自己**：结盟以我之内在定见为本。
- **比之匪人**：匪通"非"。**亲附了不该亲附的人**。象传"不亦伤乎"——岂不是受害。这是全卦唯一的负面判词（不含"无首"），错配盟友是最实际的风险。
- **外比之**：向外亲比（六四上承九五）。象传"外比于贤"——**主动向外与贤者结盟**：走出自己的小圈子。
- **显比**：**公开、透明的亲比原则**。王用三驱，失前禽：三驱之礼，天子狩猎三面驱禽、网开一面，**去者不追、来者不拒**（舍逆取顺，失前禽也）。邑人不诫：诫，告诫、警备；封邑之人不需告诫防范（一说不相警备，喻**不搞强制、不设防地自然亲附**）。象传"上使中也"——在上者以中正化下，故民自附。
- **比之无首**：亲比而**无首、无主、无本**（一说"无首"为无善始；一说为首倡之首——比附而无首领/无中心）。象传"无所终也"——**没有中心的联盟没有终局**。两解并存，结构一致：亲比需要一个可信的中心与开端。

## 二、语境

这一卦处理的问题：**人与人、组织与组织之间怎么结成可靠的亲附/联盟关系——考察什么、谁先谁后、靠什么吸引、怎么对待不来的人、联盟有没有核心。**

落到现代实际：合作伙伴选择、渠道与生态联盟、政企/校企合作、行业共同体、团队归属感建设、择友择偶择业的"亲附"决策。本卦的模型是**联盟的全生命周期**：准入尽调（原筮元永贞）→ 诚意建设（有孚盈缶）→ 内聚（比之自内）→ 外联（外比于贤）→ 公开规则（显比、舍逆取顺）→ 核心与终局（比之无首凶）。

## 三、结构

| 易学结构 | 抽出的关系结构 |
|---|---|
| 地上有水 | 亲附/渗透关系：分散要素依附于共同基座 |
| 比，辅也，下顺从 | 联盟内部有主从拓扑：中心 + 亲附节点 |
| 原筮元永贞 | 准入尽调：反复考察 + 长期守正 = 结盟的前置条件 |
| 不宁方来 | 不安者主动来附：联盟的吸引力源于提供"安定"这一公共品 |
| 后夫凶，其道穷 | 联盟有时窗：观望到最后者无位可占、信用折价 |
| 上下应也 | 双向吸引：单向拉拢不成立 |
| 有孚盈缶 | 诚意建设：诚信朴素比排场可靠 |
| 比之自内 | 内聚先于外联：不失自我才结得好盟 |
| 比之匪人 | 盟友错配是头号风险 |
| 外比于贤 | 外联：主动与更优节点结盟 |

## 四、现代转译（新断词）

> 亲比是人的常态处境：**分散的要素必然寻找共同的基座**（地上有水），问题不是"要不要结盟"，是"跟谁、按什么规矩结盟"。[转译：比，辅也；《序卦》众必有所比]

> **结盟前先尽调**（原筮）：反复考察对方的动机、记录与长期品性，且要求"元永贞"——从头到尾守正的伙伴才值得结；只看眼前利益匹配的结盟，出乱子只是时间问题。[转译：卦辞；"尽调"为引申操作化；"原"字存两解，取"反复考察"结构义]

> 联盟的吸引力来自**提供安定**：自己不安定的才来投奔（不宁方来），所以联盟方的核心产品是**稳定的预期**；而**观望到最后的人无位可占**（后夫凶，其道穷也）——亲附有时窗，优柔寡断的代价是被排除在格局之外。[转译：卦辞、彖；"时窗"为引申]

> **诚意要朴素地积累**：诚信装在瓦罐里就满（有孚盈缶），不需要排场；靠包装拉来的盟友，也会被下一次包装拉走。[转译：初六；"盈缶"存两解，取诚信充盈于朴素]

> **内聚先于外联**：结盟不失自我（比之自内，不自失也）——自己的立身之本（产品、品性、原则）先立住，再谈亲附；反过来，走出去与贤者结盟（外比于贤）同样是义务，守着小圈子不外联，格局定死。[转译：六二、六四]

> **盟友错配是头号风险**（比之匪人，不亦伤乎）：跟不该结的人绑定，受害的是自己——这是本卦唯一的硬判词，宁缺毋滥。[转译：六三]

> **结盟规则要公开、进出要自由**：显比——公开标准、公开承诺；"王用三驱，失前禽"——来者不拒、去者不追（舍逆取顺），**不强拉人入伙，不报复离场者**；不靠警备与强制维持团结（邑人不诫），靠中正自然聚人（上使中也）。[转译：九五]

> **联盟必须有可信的中心**：无核心、无首倡的联盟没有终局（比之无首，无所终也）——松散联合体要么造出一个公认的中心，要么接受散伙。[转译：上六；"中心"须换主体：由君王换为公认的规则与主事机制，标注引申]

> "下顺从"的尊卑结构是封建框架的产物：现代联盟是**平等契约下的分工**，顺从只在职责范围内成立；人身依附式亲比 [不可通约]，留白。[不可通约 + 引申]

**双向张力**：现代联盟理论（生态战略、社会网络分析、"结构洞"、信任半径）给"显比""外比于贤"分辨率——"舍逆取顺"正是生态开放策略（来去自由换网络韧性）；而"邑人不诫"照见现代病：靠竞业协议与退出惩罚捆住的"联盟"，是用诫维持的比，恰是"上使中"的反面。反过来，"比之匪人"照见另一面：现代合作话语只讲"链接一切"，从不教你**拒绝谁**；比卦把"不与谁结盟"列为第一等风险，是"连接崇拜"的解毒剂。

## 五、实践清单

- **可执行判断**：
  1. 结盟前"原筮"三查：动机（对方图什么）、记录（过往合作履约史）、长期性（元永贞——守正的稳定性），三查不过不结。
  2. 诚意台账（盈缶）：合作头三个月，每月一件朴素兑现——说到做到的小事，不靠排场造势。
  3. 内聚清单：结盟前写下自己不可让渡的三样（立身之本、原则、底线），谈判中不置换（比之自内）。
  4. 外联配额：每季度至少一次主动接触圈外的优质节点（外比于贤）。
  5. 错配熔断：发现盟友动机不纯/记录不良，设定观察期，到期不改善即降级或退出（防比之匪人）。
  6. 显比规则：入伙标准、权责、退出条件全部书面公开；进出自由，去者不追、不设报复条款（舍逆取顺）。
  7. 无强制凝聚：联盟内部靠共同收益与中正分配维系，把"诫"（惩罚性捆绑）压到最低并逐年递减（邑人不诫）。
  8. 中心机制：联合体必须确立一个公认的议事与决策中心（轮值、秘书处或公认牵头方），写进章程（防比之无首）。
  9. 时窗纪律：重大联盟机会设决策窗口，窗口关闭即作废，禁止长期观望（后夫凶）。
- **适用条件**：各方有真实的亲附需求（"不宁方来"）；存在可尽调的公开信息；愿意接受进出自由。
- **反例与边界**：
  - "下顺从"不可引申为人身依附：现代联盟是契约分工，个人有权退出；尊卑服从结构 [不可通约]。
  - "后夫凶"不是强迫站队的借口：迟到的成本是真实存在的市场现象，但不能反过来为胁迫性"入伙"背书——"舍逆取顺"明文反对强拉。
  - "比之无首"不等于鼓吹威权中心：中心可以是规则、章程或轮值机制；把"有首"读成必须有个老板，是新瓶装旧酒。
  - 联盟的成败判断须以合作数据（履约率、共同收益）验证，不以"感觉投缘"为准（硬边界 1）。
- **验证方式**：三查通过率与事后违约率对照、诚意台账兑现率、让渡清单守住率、外联活动产出、错配熔断执行记录、退出方的无报复投诉数、联盟决策中心的运转记录。

### 现代实例

**实例：开放手机联盟 OHA 的"显比"式结盟（2007）**
- 事件经过：2007 年 11 月 5 日，谷歌联合 34 家（含后续扩展口径 65 家）移动运营商、芯片商、终端制造商与软件商组建开放手机联盟（OHA），共同开发开源移动系统 Android；联盟以公开章程与开源许可（Apache 类）为规则，成员可自由定制 Android；2008 年首部 Android 手机（HTC G1）上市，Android 此后成为全球份额第一的移动系统。
- 对应结构："显比"——入伙规则公开（开源许可、章程），进出透明；"原筮元永贞"——以共同标准与长期利益而非临时算计结盟；"三驱失前禽，舍逆取顺"——成员来去自由（可基于开源底座自立定制、也可退出），联盟不强拉不报复；"比之无首"之诫的对照组：联盟有公认牵头方（谷歌）与章程式中心。
- 边界与条件：创始成员数各源口径为 34 家（含后续扩展至更多成员的不同口径，正文标区间）；OHA 官网（openhandsetalliance.com）已不可达（curl 超时），本例以行业百科与 HandWiki 词条核验，细节标"待核"；此例只检验"公开规则的联盟"结构，不评价此后 Android 生态的治理争议。

## 六、与其他卦的关联

- **07 师**：比是**师之综卦**（坎上坤下颠倒为坤上坎下）——师是内部统众，比是对外亲附；《序卦》"众必有所比"：先有众（师），后有比。一内一外，一强制一吸引。
- **19 临 / 31 咸**：临卦"咸临"的感通是亲比的上游——人心先感通，亲附才牢固；比讲关系结构，咸讲感通机制。
- **06 讼**：讼是"不亲"（《杂卦》"讼，不亲也"），比是亲——争端化解后才有亲比；"作事谋始"（讼）在比是"原筮"尽调：同一原则的两个方向（防争于未然、防错配于未然）。
- **13 同人 / 45 萃**：同人讲求同（志同道合的联合），萃讲聚（人与资源的聚集），比讲亲附（结构性结盟）——三种聚合的分工。
- **01 乾**：用九"群龙无首"是协同的高级形态，比卦"比之无首凶"却是联盟的死穴——两者的张力正说明：**松散协同可以无首（信任密集、目标一致时），契约联盟必须有中心机制**；不可混用。
