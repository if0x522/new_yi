# 05 / 水天需 / ䷄（坎上乾下）

> 主题：等待与时机——资源未备时不冒进，等待不是消极。

## 一、训诂

### 原文

**卦辞**：需，有孚，光亨，贞吉。利涉大川。

**彖曰**：需，须也；险在前也。刚健而不陷，其义不困穷矣。需有孚，光亨，贞吉。位乎天位，以正中也。利涉大川，往有功也。

**象曰**：云上于天，需。君子以饮食宴乐。

**爻辞**：
- 初九：需于郊，利用恒，无咎。象曰：需于郊，不犯难行也。利用恒，无咎；未失常也。
- 九二：需于沙，小有言，终吉。象曰：需于沙，衍在中也。虽小有言，以吉终也。
- 九三：需于泥，致寇至。象曰：需于泥，灾在外也。自我致寇，敬慎不败也。
- 六四：需于血，出自穴。象曰：需于血，顺以听也。
- 九五：需于酒食，贞吉。象曰：酒食贞吉，以中正也。
- 上六：入于穴，有不速之客三人来，敬之终吉。象曰：不速之客来，敬之终吉。虽不当位，未大失也。

### 关键字词

- **需**：《说文》"须也，遇雨不进，止须也"——本义是**遇阻而等待**。彖传自释"需，须也；险在前也"：前有坎险，故须待。《序卦》"需者，饮食之道也"，取等待期养身待时之义。核心：**等待是有条件、有动作的状态（须＝有待），不是停滞**。
- **有孚，光亨，贞吉**：孚，信实。心有实信，则光明亨通，守正而待则吉。"光"一训广大（光大），一训光明；两义可并存。占断形式弃用，转译为条件后果：等待期守住信实与正道，局面才不困穷。
- **利涉大川**：待时既至，可以渡大险——彖传"往有功也"，但此"利"以等待到位为前提，不是随时可渡。
- **刚健而不陷**：下卦乾健，上卦坎险——**内在有能力而前景有险**，故"其义不困穷"：有能力的人/组织只是条件未备，不会真被困死。这是本卦对"等待者处境"的定性。
- **云上于天，饮食宴乐**：坎为云水、乾为天——云气升于天上而未成雨，**待时而降**之象。饮食宴乐，王弼大意为"饮食宴乐以须其时"（在等待中养精蓄锐、从容度日），朱熹《本义》大意近之；非谓荒废懈怠。一说宴乐兼有"安和众心"之义（让队伍在等待期保持常态），义可并存。
- **需于郊 / 沙 / 泥 / 血 / 穴**：自远及近的**险前距离序列**。郊，邑外之地，离险最远；沙，水滨之地，渐近于险；泥，水际泥泞，将陷而未陷；血（一说为杀伤之地——王弼注大意"凡称血者，阴阳相伤"，孔颖达疏大意同；一说"血"通"洫"、沟渎之地，字源存疑不作定论），已入伤地；穴，险之深处。距离越近，容错越小。
- **利用恒**：恒，恒常、守常。象传"不犯难行也""未失常也"——离险尚远时，不主动去碰困难，守住常态节奏。
- **小有言**：小有言语责难、批评非议。象传"衍在中也"：衍，宽衍、从容（一说衍为饶裕），**心志宽绰居中**，故虽被议论而终吉。
- **致寇至**：招来祸患。象传"灾在外也"（坎险在外卦），但"自我致寇"——**险本在外，逼近险地是自己招来的**；"敬慎不败"：保持敬畏审慎才能不败。
- **需于血，出自穴**：在伤地/险中等待，终能从坑穴中脱出。象传"顺以听也"——**顺势而行、听取信息**（顺以听，一说听从于人/形势，一说听天命；本工程取"顺应形势、广收信息"的结构义）。
- **需于酒食**：在酒食（日常供给、养生之事）中等待。象传"以中正也"——居上位者的等待是**以中正维持日常秩序、养众不扰**，不是撂挑子。
- **不速之客三人来**：速，召、邀请；不速之客＝不召自来者（"三人"或指下卦三阳渐进至前）。等待结束之际往往以**意外来客/意外变量**的形式收场。"敬之终吉"：以礼敬审慎对待意外，则终吉。象传"虽不当位，未大失也"——上六居险极、位不当，但敬慎处置，故未大失。

## 二、语境

这一卦处理的问题：**前景有险、内部有能力但条件未备（资源、时机、信息不足）时，等待期怎么过——等在哪一格、等多久、等的时候做什么、什么时候不再等。**

落到现代实际：创业公司在市场/资本窗口未开时的蛰伏期、求职空窗期、产品上线前的验证期、谈判前的僵持期、大动作前的筹备期。本卦的关键洞察是：**等待是一门有内部结构的手艺**——有距离管理（郊/沙/泥/血/穴）、有心态管理（有孚、衍在中、小有言）、有日常管理（饮食宴乐）、有意外管理（不速之客），唯独没有"干等"这一项。

## 三、结构

| 易学结构 | 抽出的关系结构 |
|---|---|
| 险在前，刚健而不陷 | 前景有险 + 内在有力 = 主动等待的处境（条件未备，不是能力不足） |
| 需，须也 | 等待＝有待（有条件、有目的的行为），非停滞 |
| 有孚、光亨、贞 | 等待期的内在状态：信实、透明、守正 |
| 云上于天 | 时未至：条件在天上未成雨，酝酿期 |
| 饮食宴乐 | 等待期的日常：养精蓄锐、维持队伍常态 |
| 郊→沙→泥→血→穴 | 距离险境的梯度：越近险，容错越小，动作约束越严 |
| 初九利用恒、未失常 | 远险时守常：不因焦虑而主动犯难 |
| 九二小有言、衍在中 | 等待必挨批评：以内在定见抗噪 |
| 九三致寇至、自我致寇 | 贪近冒险＝自己招祸；敬慎才不败 |
| 六四出自穴、顺以听 | 深陷后的脱出：顺势 + 听取信息 |
| 九五需于酒食、以中正 | 主位的等待：维持日常秩序、养众不折腾 |
| 上六不速之客、敬之终吉 | 等待的收场常是意外变量：以礼敬审慎化之 |

## 四、现代转译（新断词）

> 等待的正确定性是"**条件未备，不是能力不足**"：内在刚健而前有险，此时硬闯是把险变成灾；等待是让条件追上能力。[转译：险在前也、刚健而不陷、其义不困穷]

> **等待不是干等，是"有待"**：目标在、条件清单在、倒计时在。没有条件清单的等待叫拖延，有条件清单的等待叫筹备。[转译：需，须也；引申："条件清单"为现代注入的操作化]

> 等待期的三件日常：**养精蓄锐**（饮食宴乐——王弼大意"以须其时"，不是躺平）、**维持队伍常态**（让跟着你的人照常吃饭练兵）、**守住信实与透明**（有孚，光亨——把等待的理由与进展讲清楚）。[转译：卦辞、大象；"队伍常态管理"为引申]

> **距离管理**是本卦最硬的干货：离险远时守常不犯难（需于郊，利用恒）；渐近时会有闲言碎语，心志宽绰、让时间替你说话（需于沙，小有言终吉，衍在中）；再往里一步就是泥潭——险本来在外面，**是你自己凑上去才招来祸**（需于泥，致寇至，自我致寇）。[转译：初九至九三]

> 已陷伤地时，脱出靠**顺势与听**：放下身段、广收信息、跟形势走，不硬顶（需于血，出自穴，顺以听也）。[转译：六四]

> 主位者在等待期的任务不是亲自盯着险，而是**以中正维持日常**：定节奏、保供给、稳人心（需于酒食，贞吉，以中正也）。[转译：九五]

> 等待的收场常常是**意外来客**：不请自来的变量上门时，以礼敬审慎对待，反而"终吉"——把意外纳入流程，而不是被意外打乱（入于穴，有不速之客三人来，敬之终吉）。[转译：上六；"纳入流程"为引申]

> 等待终有尽时，"利涉大川"说的是**待到条件齐了才渡**；把"利涉"提前兑现，就是九三的"致寇至"。[转译：卦辞与九三的互文]

**双向张力**：现代决策理论给"需"分辨率——实物期权（等待本身有价值，时机未熟时保留选择权）、里程碑式拨款、"承诺升级"（escalation of commitment）研究解释了人为什么在泥里还不肯退；而"需于沙，小有言"照见现代病：季度考核与舆论压力把一切等待污名化为"不作为"，逼人提前下水。反过来，"饮食宴乐"也照见另一面：以"养精蓄锐"为名的无限期舒适区，若无"利用恒"之外的条件清单与触发线，就从需卦退化成拖延——本卦的"待"始终与"恒""敬慎""贞"绑定，不给躺平背书。

## 五、实践清单

- **可执行判断**：
  1. 先写"险在哪里、缺什么"两页纸：前景风险清单 + 条件缺口清单（资源、时机、信息），缺这两样不叫等待叫逃避。
  2. 定位自己在郊/沙/泥/血/穴哪一格：用客观指标（离风险敞口多大、可撤回性多少）判断，不凭感觉。
  3. 郊位守常：不主动开辟高风险战线，维持既有节奏（利用恒，未失常）。
  4. 抗噪机制：把"小有言"预期化——预先列出可能的批评并写好回应口径，等待期不因舆论改变节奏（衍在中）。
  5. 泥位红线：禁止任何"凑上去看看"的试探性暴露（自我致寇）；确需接近险地，只做可撤回的小步动作并配敬慎清单（敬慎不败）。
  6. 血位求听：陷入困境后第一时间建立信息通道（顺以听也）——找内行、问一线、看数据，不硬顶。
  7. 主位者每日三事：定节奏、保供给、稳人心（需于酒食）；等待期不折腾队伍、不搞为显示忙碌而忙碌的动作。
  8. "不速之客"预案：列出三类可能的意外来客（突发机会、突发问责、突发变量）与礼敬处置流程（敬之终吉）。
  9. 等待触发线：写下"条件齐备即动"的客观判据与"到线即止等待"的日期，到线执行，防止无限期（利涉大川的前提管理）。
- **适用条件**：确处"险在前而条件未备"；内部能力在线（刚健）；等待期有资源维持日常。
- **反例与边界**：
  - 需不是无限期拖延：判据是条件清单与触发线；两者都写不出，按 03-屯"见几而舍"复盘处境。
  - "饮食宴乐"不支持享乐主义：原文语境是养众待时，主体是治理者；个人语境引申为休整蓄力时须设期限。
  - 突发危机不适用"需"：险已在眼前且时间以小时计时，转 07-师的应急纪律；"待"只在时间尺度允许时才是选项。
  - 本卦不预测"等多久能成"："终吉""有功"均为条件后果描述，等待期长短只能由验证指标推进（硬边界 1、2）。
- **验证方式**：条件缺口清单的收敛率、风险敞口（可撤回动作占比）、等待期团队流失率与士气指标、批评舆情与节奏变更的关联记录、触发线执行率、意外来客的处置复盘。

### 现代实例

**实例：Pixar 1986–1995 的"需于酒食"长等待（1986–1995）**
- 事件经过：1986 年，乔布斯从卢卡斯影业买下图形部门（价约 500 万美元）并另注资 500 万美元，成立 Pixar（两笔数字口径另有"共 1000 万美元含技术权利费"一说，存两解）；此后近十年，Pixar 以渲染软件、广告短片、与迪士尼合作 CAPS 等维持运转，团队保持创作与技术训练；1991 年与迪士尼签约制作三部电脑动画长片；1995 年 11 月 22 日《玩具总动员》上映，成为全球首部全电脑动画长片，等待期结束。
- 对应结构："刚健而不陷"（技术能力在而长片条件未备）＋"需于酒食，贞吉"（等待期维持日常业务与团队养众不折腾）＋等待触发线（1991 签约、1995 兑现——条件齐备即动，非无限期拖延）。
- 边界与条件：收购金额口径有 5M+5M 与 10M 两说，正文标区间；"1991 年濒临关停"等细节各源记述不一，正文不引；此例只检验"能力在而条件未备→养众待时→到线即动"结构，不预测等待期长短。
- 来源：[The Walt Disney Company：How Toy Story Changed Pixar — and Animation（HTTP 200）](https://thewaltdisneycompany.com/news/toy-story-pixar-history/)

## 六、与其他卦的关联

- **01 乾**："潜龙勿用"是需的姊妹句——潜是位未到，需是险未过；"利用恒"即"行而未成"时的常态守持。
- **03 屯**：屯"勿用有攸往"与需"需于郊"同一纪律：起步期不盲目扩张；屯重在搭结构，需重在待时机。
- **04 蒙**："初筮告，再三渎"的信息定价与需"顺以听"的信息获取互为表里。
- **06 讼**：《序卦》"饮食必有讼，故受之以讼"——需（饮食之道）之后紧跟讼：等待期与起步期的利益分配会生争端。且需与讼**互为综卦**（坎上乾下颠倒为乾上坎下）：等待与争执是同一处境的两种过法。
- **49 革**："巩用黄牛之革，不可以有为也"＝需于郊的另一种表述；"己日乃革之"＝利涉大川的触发线到点即动。
- **15 谦**："衍在中"的从容与谦卦"卑以自牧"同一路数：等待期的定力来自自我修养，不来自自我辩护。
