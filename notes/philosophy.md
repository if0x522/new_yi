# notes/philosophy.md — 马原毛概对接笔记

> 用途：记录《周易》现代转译工程与马克思主义哲学（马克思主义基本原理、毛泽东思想概论）的对接点与边界。此文件是**工具笔记**，不是哲学论文；所有对接一律遵守 METHOD.md 三条纪律与三条硬边界。

## 二、实践论 ↔ 认识论改造

古典易学的认识论是**占断**（以蓍草/随机数求神意），本工程整体弃用，替换为：

**调查—决策—执行—复盘**（对应《实践论》"实践—认识—再实践"）。

| 实践论要点 | 本工程用法 |
|---|---|
| 认识来源于实践 | 训诂先行但结论须回到现实问题（工序 2 还原语境） |
| 实践是检验真理的唯一标准 | 硬边界 1：本工程只生成假说，一切结论靠调研数据验证（每卦"验证方式"条目） |
| 感性认识→理性认识 | 抽出结构（工序 3）即从"象"到"关系结构"的理性化 |
| 认识的能动作用 | 现代重述（工序 4）不追求"符合原意"，追求"可执行判断" |
| 矛盾分析法 | 每卦必写"反例与边界"——防片面化 |

**动爻的改造**：起卦以随机数定动爻，属于占筮遗留。本工程的改造是——动爻＝"关键变量／主要矛盾的主要方面"，其位置由**调查研究**确定（哪个环节最薄弱、哪个变量决定全局），不由随机数决定。案例 1 的起卦记录仅作缘起史料保留。

## 三、群众路线 ↔ 主体观改造

| 古典表述 | 现代对接 | 对接性质 |
|---|---|---|
| 君子临民、教思无穷 | 公共服务与组织责任 | 引申（**主体必须调换**：君子→公共服务者/组织） |
| 咸（感）临 | 真诚沟通、从群众中来 | 转译 |
| 顺乎天而应乎人（革） | 客观规律 + 人民诉求 | 引申（"革命"古义为天命更替） |
| 容民畜众（师） | 动员组织群众 | 引申（主体调换） |
| 以贵下贱，大得民也（屯） | 干部下沉一线 | 转译 |
| 舟水之喻（荀子，非易） | 人民主体 | 对照材料，非本卦文本 |

**硬提醒**："人民主体"在古人框架中**无位置**——君子—小民框架是尊卑结构，不是权利结构。凡涉及处一律标注 [不可通约] 或 [引申（须换主体）]，不得径直说"《周易》主张人民主体"。这是"新瓶装旧酒"检查的重点项。

## 五、不可通约清单（留白，不得强行对接）

1. **循环史观 vs 历史唯物主义**：阴阳盛衰定数、"天之道也"的宇宙循环论，与社会形态演进的历史唯物主义相抵。本工程取"螺旋上升＋自我革命"作为修正注入，循环论处一律留白。
2. **君子—小民框架 vs 个体权利、程序正义**：原文无个体权利、无程序正义位置（如"小人勿用"无标准程序、"顺以从君"是服从伦理）。凡涉及，标注并由现代法治价值补入。
3. **占断功能**：预测吉凶的认识论功能整体弃用。"吉""凶""悔""无咎"只作训诂对象，转译时还原为行为后果的条件句。
4. **"天命"与"汤武革命"**：天命更替的合法性话语，只能取"规律＋人心"的结构义，天命观本身留白。
5. **等级尊卑（妻道、臣道）**：坤卦"地道无成而代有终"等表述的尊卑框架留白，"配合"重述为契约协作。
