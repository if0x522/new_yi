# 《周易现代转译》科普视频系列 · 制作规范

> 本目录存放全系列视频脚本：`00-intro.md`（系列片头）+ `01-qian.md` … `64-weiji.md`（每卦一集）。
> 所有脚本供 AI 视频生成 + AI 配音使用。每份脚本包含：内容定位、完整配音文案（带时间轴）、分镜表（带 AI 提示词）、拆条方案、生成备忘。

## 一、系列定位

- **系列名**：《周易现代转译》（副题：六十四卦的思想实验）
- **性质**：思想科普 / 文本解读。**不是占卜教学，不提供任何吉凶预测与命运占断。**
- **观众**：对哲学、方法论、思想史感兴趣的普通观众；每集独立可看，按主题簇成列。
- **调性**：克制、清醒、有观点。像一位严谨又不无聊的学长在讲书——不是"大师"，不是"灵修"。

## 二、合规红线（每一集都必须满足）

1. **片尾固定声明**（配音+字幕，逐字一致）：
   > "反对迷信占卜，仅解读思想。本系列只做文本解读与方法论研究，不提供任何吉凶预测。"
2. **片头 3 秒内**出现系列角标：「思想科普 · 反对迷信占卜」。
3. 画面**禁止**：算命先生、水晶球、罗盘、香炉、求签、寺庙占卜、神秘光效、星盘运势、"改运"类意象。
4. 卦象一律以「古代思想图解 / 文本结构图」的身份出现，不以"占卜工具"的身份出现。
5. 原文"吉/凶/悔/无咎"只能作为训诂对象出现，解说时一律还原为**行为后果的条件句**（做得对/做得错会怎样），绝不做未来判断。

## 三、统一视觉风格（AI 提示词风格锚）

每条画面提示词末尾**必须附加**以下风格后缀：

- **中文**：`宣纸纹理背景，水墨线条插画，朱红印章点缀，大量留白，中式极简信息动画，柔和顶光，轻微胶片颗粒；禁止神秘光效、烟雾、水晶球、宗教仪式感画面`
- **English**: `rice paper texture, ink-wash line art, vermillion accent, generous negative space, Chinese minimalist infographic motion graphics, soft top light, subtle film grain; no mystical glow, no smoke, no crystal ball, no religious ritual imagery`

色板：宣纸米白 `#F7F3E8` / 墨色 `#1F1F1F` / 朱红 `#B03A2E`（强调、印章、关键帧点缀）/ 淡墨灰 `#8A8578`（辅助线）。

## 四、统一配音规范

- 语速 **≈ 4 字/秒**（3:30 的一集 ≈ 840 字配音稿）。
- 音色：沉稳、干净、有呼吸感；忌"仙风道骨"腔、忌玄学气声、忌播音腔朗诵。
- 原文引句（卦辞/爻辞）放慢一拍、稍作停顿，用声音给"训诂"让位。
- 情绪曲线：开场钩子稍快 → 训诂段稳 → 现代转译段有力 → 实践清单段像清单一样利落 → 片尾声明严肃放慢。

## 五、单集结构（固定五段）

1. **钩子**（8–15 秒）：一个现代场景/一句反常识的话，把问题立起来。
2. **原文**（30–45 秒）：出卦名、卦画、核心卦辞/爻辞 1–2 句（配字幕原文），点出关键字词。
3. **结构**（40–60 秒）：把象剥掉，讲关系结构（配信息动画）。
4. **现代转译**（60–90 秒）：今天的判断 + 血统标注（"这句是结构转译/引申/不可通约"要说明）+ 一个真实现代实例（与 notes/examples.md 同源）。
5. **实践清单 + 片尾声明**（30–45 秒）：2–3 条可执行判断 → 固定声明收尾。

## 六、拆条规则（短视频 9:16）

- 主集超过 4 分钟时，必须提供**拆条方案**：每爻一条 30–45 秒竖版短视频（钩子 → 一句爻辞 → 一句转译 → 一句后果）。
- 拆条同样携带片尾声明（可压缩为 2 秒字幕卡）。

## 七、文件命名

`scripts/videos/NN-name.md`，与 `hexagrams/NN-name.md` 一一对应；`00-intro.md` 为系列片头。
每集脚本必须在头部写明：集数、卦名、卦画（用 Unicode 卦画字符并注明爻序，画面里爻线用矩形绘制）、预计时长、主题一句话、关键词（供检索）。
