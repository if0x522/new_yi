# 《周易》现代转译工程

> **把《周易》里的方法论内核挑出来，和现代的认识工具接上。**

既不神化为玄学，也不贬低为江湖术数。古人看到的不只是象，也是规律的雏形——只是规律的表述方式、检验方式、传输方式与现代不同。真正的分水岭不在智慧的有无，而在方法能否自我纠错、能否稳定地传给下一个不那么"神而明之"的人。

---

## 一、项目缘起

对话起点是《周易》常识介绍，随即以随机数起卦（前六数奇偶定爻、第七数对六取余定动爻），得 **地泽临 ䷒ 之 地水师 ䷆**（动在初九）。之后尝试以马克思主义哲学（唯物辩证法、矛盾论、实践论、群众路线）解读卦辞爻辞，过程中产生关键修正与方法自觉，最终确立为一门可持续推进的转译工作。

起卦只是引子。本工程的正业不是占筮，而是**把卦爻辞当作古人处理实际问题的结构化经验记录**，做训诂、抽结构、转译、检验。

## 二、方法一览（详见 [METHOD.md](METHOD.md)）

**五道工序**：训诂先行 → 还原语境 → 抽出结构 → 现代重述 → 实践检验。

**三条纪律**：结构可对接、内容不等同 / 保持双向张力（以今释古，也以古益今）/ 最终落回实践。

**四管新血**：时间观（螺旋上升＋自我革命）、主体观（人民主体）、组织观（制度化选贤任能）、认识论（调查—决策—执行—复盘，动爻＝靠调研找出的关键变量）。

**血统标注**：每条现代判断标注 [转译] / [引申] / [不可通约]，宁可留白，不可含混。

## 三、三条硬边界（不可越）

1. **不能替代实证**——只生成假说、提示盲区，结论靠调研数据。
2. **不能用于预测吉凶**——越界即塌回玄学。原文"吉""凶"只能作训诂对象，转译时还原为条件后果，不做未来判断。
3. **现代价值无对应结构处须承认不可通约**（如个体权利、程序正义、盛衰定数与历史唯物主义之抵牾），宁可留白。

**两个失败模式（自检）**：新瓶装旧酒（术语换了，思想没动）；旧瓶装空酒（大谈博大精深，落不到可执行判断）。

**易学自身依据**：《系辞》"不可为典要，唯变所适"；汉象数、魏玄学、宋理学、近世哲学皆曾注入新血，注而不垮，证明文本具强承重力。
